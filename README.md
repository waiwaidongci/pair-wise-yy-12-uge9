# hxyfront-62011 马术蹄铁修整档案 · 蹄铁师巡诊排程

源提示词编号：6

面向马术俱乐部蹄铁师的巡诊排程工作台。蹄铁师每天要跑多个马房，加急单与复查到期单在这里统一排程，避免路线被打乱。

## 业务规则

- 每匹马只保留**一张未完成巡诊单**（待排或已排），完成或撤销后才能再开。
- 马匹档案记录：马房、上次装蹄日期、蹄铁类型与状态、复查到期。
- **同一马房一天最多安排两匹马**。
- 上次装蹄**未满 14 天**，或**缺少蹄铁记录**（无上次装蹄日期）的马不排入。
- 普通复查单按复查到期先后先占名额；**加急单只能占用各马房的剩余位置**。
- 完成巡诊后填写**换蹄结论**（更换/重钉/保留、蹄铁类型与状态、下次复查、照片备注），
  换蹄后装蹄周期重新起算 14 天。
- **原安排**（每日排程快照）、**当天路线**（按马房分组排序）和**历次记录**（换蹄结论归档）均可回查；
  已开始完成的日期自动锁定，不能重排。

## 代码分层（职责分开承担）

- `src/lib/scheduling.ts` — **排程判定**：纯函数与业务常量，不碰 React 和存储，可独立测试。
- `src/lib/archive.ts` + `src/data/seed.ts` — **巡诊档案**：马匹、巡诊单、排程快照、历次记录的唯一数据仓库（localStorage 持久化）。
- `src/components/*` + `src/App.tsx` — **页面操作**：排程工作台、马匹与开单、历次记录三个页面，只调用仓库方法。

## 本地运行

```bash
npm install
npm run dev
```
