# hxyfront-62011 蹄铁巡诊排程

源提示词编号：6

面向马术俱乐部蹄铁师的巡诊排程前端。蹄铁师每天要跑多个马房，加急单与复查到期容易把巡诊路线排乱；本工具把“排程判定、巡诊档案、页面操作”拆开承担：

- **排程判定**（`src/scheduling/`，纯函数）
  - 同一马房一天最多安排两匹马；
  - 上次装蹄未满十四天、或缺少蹄铁记录的马不排入；
  - 常规复查到期马先排，加急单只能占用剩余位置（不能挤掉常规马）；
  - 每匹马只允许存在一张未完成巡诊单（在档案层保证）。
- **巡诊档案**（`src/archive/`）：马匹档案（马房、上次装蹄日期、蹄铁状态、复查到期、历次装蹄记录）、未完成巡诊单、当天排程、原安排留档与换蹄结论；localStorage 持久化。
- **页面操作**（`src/components/`）
  - 当天路线：按马房查看排程、跳过原因、写换蹄结论、重新排程（原安排自动留档可对照）；
  - 排程判定：逐张巡诊单展示“能不能排、为什么”；
  - 巡诊档案：马匹卡片、开/撤加急单、历次装蹄记录、新增马匹；
  - 历次记录：已完成巡诊的换蹄结论、历史排程单与原安排。

技术栈：React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```
